Description: The cell_towers_world table stores information about various cell towers across the globe. The data includes radio type (GSM, UMTS, LTE, CDMA), Mobile Country Code (MCC), network code (net), area code, cell identity, unit, geographic coordinates (longitude and latitude), range, number of samples, changeability, creation and update timestamps, and average signal strength.

Applications: This table can be useful for various applications such as:
1. Telecommunication companies to manage and monitor their network infrastructure.
2. Mapping and visualizing cell tower locations for analytical purposes.
3. Analyzing network coverage and signal strength in different regions to improve customer's service quality.
4. Assisting with efficient network planning and optimization.
5. Facilitating emergency response teams in locating and identifying cell towers during disaster recovery efforts.

Keywords: cell tower, radio, technology, mobile country code, network, area, cell identity, geographic coordinates, signal strength, timestamp, network infrastructure, coverage, mapping, optimization, emergency response.

Column descriptions for cell_towers_world table:
- cell_towers_world.radio: The radio type used by the cell tower.
- cell_towers_world.mcc: The Mobile Country Code of the country where the cell tower is located.
- cell_towers_world.net: The Network Code of the network operator owning the cell tower.
- cell_towers_world.area: The cell tower location area code.
- cell_towers_world.cell: The unique identifier number of the cell tower within a location area.
- cell_towers_world.unit: The unit ID used to identify a group of cells within a base station.
- cell_towers_world.lon: The longitude of the cell tower location.
- cell_towers_world.lat: The latitude of the cell tower location.
- cell_towers_world.location: The geometric coordinates of the cell tower location, encoded as a POINT.
- cell_towers_world.range_: The estimated coverage range of the cell tower in meters.
- cell_towers_world.samples: The number of signal samples used to determine the average signal strength.
- cell_towers_world.changeable: A binary indicator of whether the cell tower location and range can be updated.
- cell_towers_world.created: The timestamp of when the cell tower record was created.
- cell_towers_world.updated: The timestamp of when the cell tower record was last updated.
- cell_towers_world.average_signal: The average signal strength of the cell tower in dBm.
