Description: The airports table stores information about airports from around the world, including their location, size, and various codes associated with them. The primary functionality of this table is to provide data on airport details, such as their identification, type (small_airport, heliport, closed, medium_airport, seaplane_base), geographical coordinates (latitude and longitude), and region information (continent, iso_country, and iso_region). Secondary functionalities include recording airport-specific information, such as the municipality it serves, whether it has scheduled services, and associated codes (gps_code, iata_code, and local_code). The table also stores links to official websites (home_link) and Wikipedia articles (wikipedia_link) for reference, as well as any associated keywords for indexing and search purposes.

Applications: This table can be used for a variety of applications, such as mapping and visualizing airport locations, analyzing airport distribution by region, and conducting airport viability studies. It can also serve as a reference for travel-related software or websites to help users find specific airport information, provide data for flight planning and booking systems, and aid aviation authorities and regulatory institutions in managing global aviation activities.

Keywords: Airport data, Airport identification, Airport types, Geographical coordinates, Regional information, Airport codes, Scheduled services, Airport websites, Wikipedia articles, Airport mapping, Aviation industry, Travel information, Flight planning.

- id: unique identifier for each airports row
- ident: airport identifier code
- type: type of airport (e.g. small_airport, heliport, closed)
- name: name of the airport
- latitude_deg: latitude of the airport location
- longitude_deg: longitude of the airport location
- elevation_ft: elevation of the airport above sea level in feet
- continent: continent where the airport is located
- iso_country: ISO code for the country where the airport is located
- iso_region: ISO code for the region where the airport is located
- municipality: municipality where the airport is located
- scheduled_service: whether the airport has scheduled commercial flights
- gps_code: GPS code for the airport
- iata_code: IATA code for the airport
- local_code: local code for the airport
- home_link: link to the airport's official website
- wikipedia_link: link to the airport's Wikipedia page
- keywords: keywords associated with the airport (e.g. Cheonmi-ri, Manhattan, Victorian Aerial Fire Bases)
