Description: The sp500_companies table is designed to store information about companies belonging to the S&P 500 index. Each row in the table represents a single company with their stock symbol, name, and sector. The primary functionality of this table is to maintain a reference for the stock market symbols (tickers) and the corresponding company names in the S&P 500 index, as well as to categorize them into different sectors based on their industry, which serves as the table's secondary functionality.

Applications: This table can serve as a valuable resource for various use cases and applications, such as:
1. Stock market analysis and research tools to provide reference data for S&P 500 index constituents.
2. Financial news aggregators and content creation platforms can leverage this table to generate reports, insights, and analyses on different industry sectors and companies.
3. Portfolio management and trading systems can use the sp500_companies table to identify potential investment opportunities or build diversified portfolios based on different sectors.
4. Educational and research institutions studying the stock market and its relation to macroeconomic trends can use this database for analysis and comparative studies.

Keywords: S&P 500 index, stock market, companies, sectors, industries, financial data, portfolio management, market analysis, investment research, trading systems.

- Symbol: This column stores the stock symbol for each company in the S&P 500 index. It uses a TEXT data type with a dictionary encoding for efficient storage and query performance.
- Name: This column stores the name of each company in the S&P 500 index. It also uses a TEXT data type with a dictionary encoding.
- Sector: This column stores the sector in which each company operates. It uses a TEXT data type with a dictionary encoding. The possible values for this column are Information Technology, Industrials, Financials, Health Care, and Consumer Discretionary.
